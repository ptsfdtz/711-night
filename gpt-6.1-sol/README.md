# 雨の街角 · Rainy Corner

没有人物、没有屏幕 UI 的日式便利店雨夜三维微缩场景。

直接用现代浏览器打开本文件夹中的 `Rainy-Corner.html` 即可观看，所有代码和贴图均已内嵌，无须联网或启动服务。

- 左键拖拽：旋转。
- 滚轮：缩放。
- 右键拖拽：平移。
- 触屏：单指旋转，双指缩放及平移。

正方形底座承载便利店、转折街道和小巷。店内陈设包括商品货架、饮料柜、饭团陈列、收银台、咖啡机、关东煮柜台、杂志架、冰柜、吊牌、储物柜和后场门。外部包含贩卖机、自行车、雨伞架、垃圾桶、路灯、架空电线、路牌、护栏、停车位、斑马线、排水沟、空调外机、公告栏等。

持续降雨、檐口滴水、积水波纹、玻璃水痕、轻微招牌闪烁、自动门周期开合和交通信号灯轮换均为实时动效。路面使用平面反射及随雨波动的灯光倒影。模型和文字贴图由代码生成。

## 开发

在本文件夹内执行：

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

重新打包：`npm.cmd run build`。该命令会更新 `dist` 和独立的 `Rainy-Corner.html`。
