# Kimi K3.1 Pro - Rainy Night Store

A Three.js miniature scene. Drag to orbit, scroll or pinch to zoom, and right-drag to pan.

Run `python -m http.server 18990 --bind 127.0.0.1` from the repository root, then open http://127.0.0.1:18990/kimi-k3.1-pro/

Online: https://ptsfdtz.github.io/711-night/kimi-k3.1-pro/

`index.html` and `assets/` are the static release, using relative paths for GitHub Pages. Source files remain in `src/`. To rebuild, use Vite with `base: "./"`, then copy the generated HTML and assets into this directory.
