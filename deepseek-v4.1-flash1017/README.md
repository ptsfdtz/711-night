# 星マート — 雨の街角

一个可以直接在浏览器中观看的三渲二雨夜便利店街角微缩模型。便利店、街道和所有小道具都建在一个完整的正方形底座上，没有页面 UI，只有场景本身。

## 打开方式

直接双击 `index.html` 即可（Three.js 已放在本文件夹的 `vendor/` 中，不依赖网络）。

如果本机浏览器对 `file://` 有限制，也可以在本文件夹运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 操作

- 鼠标左键拖拽 / 单指拖动：旋转视角
- 滚轮 / 双指捏合：缩放
- 相机不会穿到地面以下，也不依赖任何界面按钮

## 场景内容

便利店：环绕式玻璃橱窗、自动门、屋檐雨棚、门口地垫、24H 招牌、灯箱、自动贩卖机、自行车、雨伞架、分类垃圾桶、公告栏、空调外机、后场门与储物柜。

街道：街角斑马线、停车位、排水沟、积水与涟漪、路灯、电线杆与电线、路牌、街角护栏、小巷入口、红邮筒、长椅、行道树和一辆靠在护栏边的自行车。长椅上还有一只避雨的小猫。

店内：饮料冷柜、便当与饭团区、零食货架、杂志架、收银台、咖啡机、热食柜、关东煮、冰淇淋冰柜、购物篮、地面导视、海报和灯箱。

动态：持续降雨、屋檐滴水、积水波纹与雨滴溅落、自动门偶尔开合、玻璃上的雨痕、招牌轻微闪烁、交通信号灯慢速变化，以及湿路面上的灯光反射。

## 文件结构

```
index.html
styles.css
src/
  core.js       材质、几何体与建模辅助
  textures.js   全部程序化绘制的招牌、海报、包装等纹理
  store.js      便利店建筑、内部陈列与灯光
  props.js      街道道具（电线杆、自行车、信号灯、猫等）
  world.js      底座、街道、水洼、反射与场景编排
  atmosphere.js 雨、溅水、滴水与薄雾
  post.js       小型 Bloom 后处理
  main.js       渲染器、自由轨道相机与动画循环
vendor/
  three.min.js
preview.png
```

所有招牌、海报、杂志封面、包装纹理均由 Canvas 在运行时绘制；没有外部图片或字体依赖。
